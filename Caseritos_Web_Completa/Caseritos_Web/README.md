# Caseritos — web funcional
Landing page responsive basada en la interfaz proporcionada.

Incluye:
- Navegación responsive.
- Hero con mockups de la app.
- Menú del día.
- Botones Pedir con modal funcional.
- Botón de menú completo.
- CTAs de descarga.
- Sección de funciones, estadísticas y blog.
- Newsletter con validación básica.
- Diseño adaptable a móvil, tablet y escritorio.

Para probar:
1. Extrae el ZIP.
2. Abre index.html directamente, o ejecuta `python -m http.server 8000` dentro de la carpeta.
3. Las URLs reales de App Store/Google Play deben sustituirse en los botones de descarga cuando estén disponibles.
